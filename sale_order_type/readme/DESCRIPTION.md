This module adds a typology for the sales orders. In each different
type, you can define an invoicing and refunding journal, a sequence, a
payment term, a pricelist, an analytic account and a quotation validity.

You can see sale types as lines of business.

You are able to select a sales order type by partner so that when you
add a partner to a sales order it will get the related info to it.

Stock related settings (warehouse, stock routes, shipping policy and
incoterm) are provided by the `sale_order_type_stock` module, which is
automatically installed alongside `sale_stock`.
